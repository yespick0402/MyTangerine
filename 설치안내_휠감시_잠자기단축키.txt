00Favorite 4.8 — 안전 모드 진단 + 잠자기 단축키 설정 (HK2)
===============================================================
빌드 식별자: FAV-20261120-HK2

중요: 이전 Shift / Shift+Command 테스트 실패의 근본 원인은 아직 실기 확인 전입니다.
이전 빌드 대비 원형 휠의 CGEventTap 이벤트 처리 본문이 동일함을 비교했습니다.
앱 이름 변경/임시 서명 재빌드로 macOS 입력 모니터링 또는 손쉬운 사용 권한이
다시 요구되는 가능성에 대비한 진단·재연결 기능을 추가했습니다.

수정 내용
---------
1) 잠자기 방지 전역 토글 단축키를 '설명 및 설정 → 단축키 설정'에 배치
2) 기존 ⌃⌥⌘K/J/L 및 '사용 안 함' 선택 유지
3) '단축키 직접 입력'으로 Control을 포함한 수정키 2개 이상 + 영문 A~Z 지원
   충돌로 등록에 실패하면 기존 단축키를 복원하고 실패 안내
4) 단축키 입력 중 기존 전역 단축키의 토글 이벤트 일시 정지
5) 휠 입력 감시 연결 상태 및 '감시 재연결' 기능 제공
6) 입력 모니터링/손쉬운 사용 macOS 시스템 설정 바로가기
7) 메뉴바 상단에 '빌드 확인: FAV-20261120-HK2' 표시
8) 잠자기 방지 ON/OFF 케이크 아이콘 유지, 파일 변환과 독립 유지
9) 기존 listenOnly 휠 감시 이벤트 처리 및 Finder 네이티브 드롭 본문 변경 없음
10) 실행 중 반복되는 NSApp.applicationIconImage 덮어쓰기 제거

다른 위치의 구버전 앱이 동시에 실행되지 않도록 확인하세요.

실사용 검사 (중요)
------------------
1. 메뉴바 클릭 → '빌드 확인: FAV-20261120-HK2'가 있는지 확인.
2. 메뉴바에서 '휠 감시 연결됨' 확인. 연결되지 않으면
   '설명 및 설정 → 단축키 설정 → 감시 재연결' 선택.
3. 실패 시 macOS 시스템 설정 → 개인정보 보호 및 보안 →
   '입력 모니터링' 및 '손쉬운 사용'에서 00Favorite 권한을 확인하고
   앱 종료/재실행한 후 2번을 다시 확인.
4. '휠 감지 켜기' ON 및 'Finder에서 시작한 파일 드래그만 감지' ON 확인.
5. 복사한 PNG 파일 드래그 시작 → Shift 누르기 → CONVERT 휠 표시 확인.
6. JPG 조각에 파일 드롭 → JPG 파일이 실제 생성되는지 확인.
7. 동일한 드래그 흐름에서 Shift+Command 유지 → JPG 드롭 →
   화질 선택 창이 열리는지 확인. Command만 떼면 일반 변환 복귀하는지 확인.
8. 설명 및 설정 → 단축키 설정 → 잠자기 방지: 기본 ⌃⌥⌘K, 직접 입력,
   토글 OFF/ON, 수동 5분 종료, 검은/흰 케이크 전환 확인.
9. Finder 일반 이동 및 Option-드래그 복사가 종전처럼 정상인지 확인.

실패 증상 기록법
---------------
A. 휠이 아예 표시되지 않음 = 권한/감시 연결/설정 상태 우선 확인
B. 휠은 보이는데 조각 선택·드롭이 안 됨 = 파일 드래그 대상 판별 추가 진단 필요
C. 드롭은 됐지만 결과 파일 생성 실패 = 변환 엔진/폴더 접근/파일형식 진단 필요
A/B/C 중 어느 경우인지 결과와 함께 알려주면 다음 수정을 정확히 할 수 있습니다.
